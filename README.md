# JavaScript Mini Projects - Batch 13

This repository contains two mini JavaScript projects for learning purposes:

1. **Expense Calculator**  
2. **Book List App**  

---

## 1️⃣ Expense Calculator

**Description:**  
A simple web app to keep track of expenses. Users can add expense amounts, see the total, and have instant validation.

**Features:**  
- Add expense amount to a list  
- Calculate total expense using `reduce()`  
- Input validation (empty or invalid values blocked)  
- Dynamic display of expense list  
- Pressing **Enter** also adds the expense  

**Files:**  
- `index.html` – HTML structure  
- `style.css` – Basic styling  
- `script.js` – JavaScript logic  

**How to use:**  
1. Open `index.html` in a browser.  
2. Enter an amount in the input box.  
3. Click **Add** or press **Enter**.  
4. See total and the list of expenses updated instantly.

## 2️⃣ Book List App

**Description:**  
A web app to save books and authors in a dynamic table. Data is persistent using **LocalStorage**.

**Features:**  
- Add Book Name and Author Name  
- Dynamically create a table row using `document.createElement('tr')`  
- Delete a book using **Delete button** (Event Listener / Event Bubbling)  
- Data persists on page refresh using **LocalStorage**  
- Input validation for empty fields  

**Files:**  
- `index.html` – HTML structure  
- `style.css` – Basic styling  
- `script.js` – JavaScript logic  

**How to use:**  
1. Open `index.html` in a browser.  
2. Enter Book Name and Author Name.  
3. Click **Save**.  
4. Book appears in the table.  
5. Click **Delete** to remove a book.  
6. Refresh the page → table data persists.
